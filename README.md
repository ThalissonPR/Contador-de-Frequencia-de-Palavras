# Contador de Frequência de Palavras

## Sobre o projeto

Este projeto foi desenvolvido em **C++** com o objetivo de analisar e comparar o desempenho de diferentes estruturas de dados na contagem de frequência de palavras em arquivos de texto.

A aplicação implementa estruturas genéricas, incluindo **árvores balanceadas** e **tabelas hash** com diferentes estratégias de tratamento de colisões, permitindo avaliar o comportamento de cada abordagem durante as operações de inserção e busca.

Além da contagem de palavras, o projeto oferece suporte à manipulação de **Unicode**, ordenação utilizando **Collator** e iteradores personalizados, possibilitando o processamento correto de textos com caracteres acentuados e outros símbolos.

## Objetivos

* Contar a frequência de palavras em arquivos de texto.
* Comparar o desempenho de diferentes estruturas de dados.
* Medir o tempo de execução das operações.
* Analisar a quantidade de comparações realizadas.
* Avaliar o número de rotações executadas pelas árvores balanceadas.

## Tecnologias

* C++
* Estruturas de Dados Genéricas
* Árvores Balanceadas
* Tabelas Hash
* Unicode
* Collator

## Resultados

Os experimentos realizados permitiram comparar a eficiência das diferentes estruturas de dados em cenários de contagem de palavras, evidenciando como a escolha da estrutura adequada influencia diretamente o desempenho da aplicação.
